## Tips para tomar las capturas

1. **Resolución**: usá pantalla completa (o al menos 1280×720px).
2. **Datos de prueba**: antes de sacar las capturas, cargá algunos productos, ventas y gastos de prueba para que la pantalla no aparezca vacía.
3. **Resaltar elementos**: podés usar una herramienta como Paint o la herramienta de recorte de Windows para agregar flechas rojas o círculos que señalen el elemento indicado.
4. **Formato**: guardá las imágenes en formato `.png` con el nombre exacto del ID.
5. **Usuario admin**: para las secciones de administrador, asegurate de estar logueado con un usuario con rol ADMINISTRADOR.
6. **Carpeta de destino**: todas las imágenes van en `docs/manual/images/`.
